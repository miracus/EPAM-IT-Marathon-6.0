## Як переглянути і як редагувати

**Переглянути (будь-хто, без акаунта):**
- **Репозиторій.** Відкрий посилання вище. Markdown-файли (`README`, `FIGMA.md`, `USER_STORIES_v3.md`, `CHANGELOG_v2.md`) і PNG показуються прямо на GitHub. Файли `.docx` GitHub не показує: відкрий файл і натисни **Download raw file**.
- **Прототипи.** Посилання GitHub Pages вище. Ліворуч є перемикач станів; кнопки, вкладки й степери клікабельні.
- **Figma.** Посилання вище. Власник файла вмикає **Share → Anyone with the link → can view**.
- **Усе одним архівом:** зелена кнопка **Code → Download ZIP**.

**Редагувати:**
- **Учасники команди.** Власник репозиторію: **Settings → Collaborators → Add people** → логін GitHub, роль *Write*. Після прийняття запрошення учасник може змінювати файли прямо на сайті (іконка олівця) або клонувати репозиторій і пушити.
- **Будь-хто інший** робить **Fork**, вносить зміни у своїй копії і відкриває **Pull request**. Власник переглядає зміни і зливає їх.
- **Figma.** Власник: **Share → Invite** → email → *can edit*. Щоб кілька людей могли редагувати, файл краще перенести з Drafts у проєкт команди.
- **Word-файли (`T1/*.docx`).** Завантаж файл, відредагуй у Word або Google Docs і заміни у репозиторії: **Add file → Upload files** з тим самим ім'ям, потім *Commit changes*.
